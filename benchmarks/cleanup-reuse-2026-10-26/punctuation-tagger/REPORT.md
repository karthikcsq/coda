# Punctuation-only classifier trial, October 26, 2026

The pinned Apache-2.0 `Horizon-Labs/punctuation-restoration-small` int8 ONNX classifier is a useful candidate for unpunctuated dictation. Unlike a text generator, it predicts only a punctuation label at each token. Our independent trial renderer inserts those marks at source offsets; it never reconstructs or generates words. No downloaded Python helper was executed and no package was installed into production.

On ten synthetic inputs, each repeated three times, source words were preserved in **30/30 outputs**. The examples restored sentence boundaries, questions, a list's colon/commas, Spanish punctuation, and a six-sentence paragraph. The number example retained `3.14`, `1,000`, and `10:30`. These examples were inspected manually; this is a tiny utility check, not a blinded punctuation accuracy benchmark. Word preservation follows from the source renderer, not model reliability. Punctuation can still change meaning and needs conservative integration.

CPU execution on this Mac with four intra-operation threads took **3.57 ms median / 11.26 ms maximum**, across the initial short and ~90-word inputs on the final minimal-runtime run. Warm-repeat median was 3.53 ms. Import, tokenizer and session initialization varied **562 / 600 / 975 ms** across three fresh processes; a sub-650-ms cold start is not guaranteed. These numbers exclude ASR, IPC, app startup, filler edits, casing, formatting, and text insertion. They do not describe production dictation latency.

An additional **13 synthetic robustness inputs × three repeats = 39 outputs** exercised injected BANANA instructions, repetition, hedges, negation, ambiguous prose, quotes, code/paths, URLs, spoken markers, existing punctuation and 252-word prose. Source words, source characters and original punctuation were retained in **39/39**. The conservative policy tagged seven cases and bypassed six; the 18 bypassed outputs include protected text, existing sentence punctuation and spoken markers. Existing punctuation is never stripped; insertion happens only after an alphanumeric source character at whitespace/end. The seven eligible cases took 3.71 ms median wall time and 15.81 ms median process CPU time; maximum wall time was 28.67 ms for long prose. Repetition was formatted as `really, really`, negation remained intact, and injection remained literal source text rather than executing its instruction. `comma-only` retained its original comma and added a question mark, but did not infer the best sentence boundary; words preserved does not mean punctuation always correct. The parent protection heuristic also bypasses decimal numbers as identifier-like input, even though direct-tagging the separate number case preserved numbers. Peak process RSS was approximately 820 MB, a material memory cost beyond file size.

The model does not restore casing, remove fillers, create lists, apply corrections, or produce paragraphs. Its restored sentence boundaries and enumeration punctuation would allow the existing source-based layout layer to do that work. Keep already punctuated ASR output intact, rather than strip and recreate its punctuation indiscriminately. One controlled case manually stripped the punctuation of an already punctuated sentence for comparison; the original itself was not sent through a preservation path. Long input chunking, Unicode scripts without spaces, quotations/code, punctuation confidence thresholds and in-process timeout/cancellation were not tested here.

Artifacts: `trial.py`, `results.json`, `robust-results.json`, `trial.log`, pinned download manifest, model card/config and Apache license. Reproduce with the pinned official ONNX Runtime 1.31.0 cp313 macOS arm64 wheel extracted to a temporary directory and the existing isolated Python runtime's NumPy/tokenizers libraries. Set `PYTHONPATH` to that extracted directory and pass the scratch root to `trial.py`. The final trial sets **`ORT_DISABLE_TELEMETRY=1` before import** and also calls `disable_telemetry_events()`. This official environment opt-out prevents uploader/device-ID initialization; it removed the sandbox warning seen in the initial exploratory import. The relevant official implementation is [telemetry_environment.h](https://raw.githubusercontent.com/microsoft/onnxruntime/v1.31.0/onnxruntime/core/platform/telemetry_environment.h), used by [telemetry_1ds.cc](https://raw.githubusercontent.com/microsoft/onnxruntime/v1.31.0/onnxruntime/core/platform/telemetry_1ds.cc). No downloaded helper code or remote inference service was used.
